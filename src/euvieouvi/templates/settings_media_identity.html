Identificação de mídias

Mapeie as pastas que apontam para os mesmos arquivos físicos. Não é necessário montar os arquivos no euvieouvi: os caminhos são informados pelos servidores.

Use uma linha por pasta: origem => compartilhado. Exemplo: Plex /mnt/series => /shared/series e Jellyfin /media/tv => /shared/series. A comparação respeita maiúsculas e não usa apenas nomes de arquivos. Não mapeie pastas com conteúdos diferentes para a mesma raiz.
