Webhooks de conclusões

Estas URLs contêm um token secreto. Use-as somente nos servidores configurados e não as publique.

Plex

Adicione a URL abaixo em Settings → Account → Webhooks. A atividade atual mostra todos os usuários Plex.

Informe exatamente o Account.title (nome de usuário) ou Account.id do Plex. Somente esse usuário alimentará o histórico, marcará o catálogo como assistido e propagará o estado para o Jellyfin. Deixe vazio para aceitar conclusões de todos os usuários. A atividade em reprodução nunca é filtrada.

Jellyfin

No plugin oficial Webhook, crie um destino Generic Form, habilite Playback Start, Playback Progress e Playback Stop, e use a URL abaixo.

Não deixe Fields vazio: o plugin não envia a requisição nesse caso. Conclusões são registradas somente quando PlayedToCompletion=true.
